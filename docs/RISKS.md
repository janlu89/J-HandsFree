# Risk register

Likelihood and impact are rated **High**, **Medium** or **Low**. The register is reviewed at the end of every phase.

| ID | Risk | Likelihood | Impact | Mitigation | Status | Checked in |
| --- | --- | --- | --- | --- | --- | --- |
| R-01 | Google blocks sign-in inside an embedded WebView ("This browser or app may not be secure"). | Medium | High | Keep the default user agent, which works on WebView 155. Fallbacks in order: the user agent without the `; wv` marker, then personal playlists set to unlisted, opened by link without signing in. | Did not occur in the spike; Google can change it at any time | Phase 0, 3 |
| R-02 | Android freezes or mutes audio from an app without a valid foreground service (enforced from Android 17). | Medium | High | Media3 `MediaSessionService` with type `mediaPlayback`, always started from the visible UI. Keep the service during short pauses, stop it after the pause timeout. | Mitigation validated on Android 14; Android 17 not yet observed | Phase 0, 4 |
| R-03 | The Activity is destroyed in the background and takes the WebView with it. | Low | High | None needed: the Activity survived up to 75 minutes in the background. The spike lost the WebView only when the whole process was killed, which R-06 covers. | Did not occur in the spike | Phase 0 |
| R-04 | YouTube changes its page markup and selectors stop matching. | High | Medium | All selectors in one module; snapshot tests; health warning; remote selector updates as data. | Open | Phase 3, 5, 6 |
| R-05 | The Skip button ignores script clicks because they are not trusted events. | High | High | Native tap: the script reports the button rectangle and the bridge dispatches a `MotionEvent`. Script clicks are not used ([ADR 0013](adr/0013-native-tap-to-press-skip.md)). | Occurred; mitigated: the native tap skipped 20 ads out of 20 | Phase 0, 5 |
| R-06 | The phone maker's battery manager, or Android itself, kills the app in the background. | High | High | Foreground service whenever audio plays, started by the page's `playing` state; allow the page to be hidden after the pause timeout; one-time prompt to exclude the app from battery optimization; link to vendor-specific guidance in the README. | Occurred without the foreground service: HyperOS killed cached processes 10 minutes after the screen locked, Android killed them for CPU use. With the service, to be confirmed in step 4.7 | Phase 0, 4 |
| R-07 | Android System WebView on the device lacks the WebKit features the app needs. | Low | High | Feature detection at startup with a clear message to update Android System WebView. | Open | Phase 3 |
| R-08 | .NET bindings for Media3 or AndroidX WebKit lag behind or miss APIs. | Medium | Medium | Pinned, aligned AndroidX versions and Android 6.0 as the minimum ([ADR 0014](adr/0014-androidx-alignment-and-android-6-minimum.md)). Fallback: a small Java binding or `MediaSessionCompat`. | Occurred as version conflicts with MAUI 10; mitigated, both bindings work | Phase 0, 8 |
| R-09 | The signing key is lost. | Low | High | Offline backup of the keystore and passwords in a password manager. | Open | Phase 1 |
| R-10 | YouTube treats the automation as a Terms of Service violation and limits the account. | Low | Medium | Personal use only; no store publishing; human-like timing (skip only after the button appears). Accepted risk. | Accepted | Ongoing |
| R-11 | YouTube changes ad formats, for example fewer skippable ads or no Skip button in server-inserted ads. | Medium | Medium | Out of the app's control. The app keeps working as a background player even if no ad is skippable. | Accepted | Ongoing |
| R-12 | The .NET 11 migration introduces runtime regressions on Android (CoreCLR becomes the default). | Medium | Medium | Dedicated phase with a field test; .NET 11 can temporarily fall back to Mono with an MSBuild property while an issue is reported. | Open | Phase 8 |
| R-13 | A secret is committed to the public repository. | Low | High | Secrets only in GitHub Actions; `.gitignore` covers keystores; enable GitHub secret scanning and push protection. | Open | Phase 1 |
| R-14 | Scope creep for a solo developer. | Medium | Medium | MoSCoW priorities in [FEATURES.md](FEATURES.md); phase 6 selection confirmed before starting. | Open | Every phase |
| R-15 | Mediator 3.0.2 predates .NET 10; explicit .NET 10 support is listed only in the 3.1 release candidate. | Low | Low | The package targets .NET Standard 2.0. Phase 1 verifies generation and a trimmed Release build; if it fails, move to the latest stable 3.x. | Open | Phase 1 |
| R-16 | The WebView reports itself as visible in the background, so the page keeps running: CPU, battery and memory use stay high (300 to 500 MB with the renderer), and a cached process doing this is killed. | High | Medium | Foreground service while playing; allow the page to be hidden after the pause timeout ([ADR 0012](adr/0012-native-window-visibility-for-background-playback.md)); measure battery use in the field test. | Open | Phase 4 |
